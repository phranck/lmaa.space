# Brand marks

Logos of other companies, used to mark a route out of the page. They are their owners' trademarks and are not ours to redraw, recolour, or rebuild, so each file goes in exactly as its owner publishes it.

## github-lockup.svg

`GitHub_Lockup_Black_Clearspace.svg` from GitHub's own logo pack at <https://brand.github.com/GitHub_Logos.zip>, linked from <https://github.com/logos>. GitHub allows the logo to identify a GitHub presence and to link to GitHub, which is what it does here on the GitHub Sponsors block. The clearspace version already carries the margin GitHub asks for around the mark, so nothing further is added around it.

## paypal-lockup.svg

`PayPal.svg` from Wikimedia Commons, in the revision of 30 December 2024, which comes from PayPal's own `paypalobjects.com/webstatic/i/logo/rebrand/ppcom.svg`. Commons holds the drawing itself to be public domain because it is below the threshold of originality, whilst the mark remains PayPal's trademark. It identifies the PayPal block and links to PayPal, which is what a trademark may be used for.

## sepa-lockup.svg

`logo-sepa.svg` as served by Curo Payments at <https://www.curopayments.com/wp-content/uploads/logo-sepa.svg>. The mark belongs to the European Payments Council, and this copy comes from a payment provider rather than from the council itself, so the provenance is weaker than the two above. The file carries paths only, with no script, no external reference, and nothing that loads at render time. It labels the transfer block, which is what the mark is for.

The payment logos live elsewhere, in `packages/ui/src/assets/payment-methods/`, because a shop's accepted methods use them too.
